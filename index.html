Featured Project
ARGUS — Adaptive Reasoning with Guided Uncertainty Sampling

Multi-Agent LLM System · Deployed · 2026

Designed and built a self-auditing multi-agent LLM reasoning system implementing semantic entropy-based uncertainty quantification (Kuhn et al., ICLR 2023). Rather than trusting a single model response, ARGUS samples the LLM multiple times, clusters responses in embedding space using agglomerative clustering, and computes Shannon entropy over the cluster distribution — routing to an extended reasoning loop when epistemic uncertainty exceeds a calibrated threshold.

The pipeline comprises five specialised agents (Planner, Retriever, Reasoner, Critic, Synthesis) orchestrated via a LangGraph StateGraph with conditional edges. The Critic performs a six-dimension rubric audit — scoring logical coherence, factual grounding, completeness, calibration, relevance, and conciseness — before a final calibrated answer is synthesised. Deployed live with a FastAPI backend, Streamlit dashboard, Docker image published to GHCR, and full CI/CD via GitHub Actions.

UK Higher Education Analytics Platform

End-to-End Analytical Data Platform · 2026

Designed and built a production-grade analytical data platform covering 30 UK higher education providers across 10 academic years of enrolment and degree classification data. The pipeline implements a full ETL workflow with Pandera schema validation, a star-schema dimensional model in DuckDB, and six SQL analytical views using window functions for year-on-year trend analysis.

Key engineering decisions included choosing DuckDB for its native columnar window function support, enforcing explicit schema contracts to catch data quality issues before they propagate downstream, and designing a six-page interactive dashboard segmented by study level, domicile, subject group, and region — built for non-technical stakeholders. Maintained via GitHub Actions CI with 15 automated pytest tests covering the full pipeline.

Featured Project
PowerLine Vision: Aerial Cable Detection

Computer Vision · Deep Learning · 2026

Built an end-to-end computer vision pipeline for the automatic detection of overhead power line cables from aerial imagery, directly addressing a real-world infrastructure intelligence challenge in electricity distribution. Fine-tuned a YOLOv8 CNN on annotated aerial datasets, achieving mAP@0.5 of 0.688, Precision of 0.758, and Recall of 0.647 across 2,738 evaluated instances.

The pipeline combines classical OpenCV preprocessing (CLAHE contrast enhancement for variable aerial lighting) with modern deep learning, multi-scale CNN feature fusion, and a full MLOps stack including CI/CD, drift detection, and real-time video inference. Unit tested throughout with precision-recall curve analysis and confusion matrix reporting.
